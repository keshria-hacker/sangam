# UI craft

## When to use

The user wants a page, component, or prototype that should feel
designed rather than assembled from a template.

## Anti-template rules

1. Real content first: use the user's actual words, numbers, and
   names. Never ship lorem ipsum, "Feature one", or a stock hero.
2. No default three-card feature grid, no generic gradient hero, no
   "Lorem ipsum dolor" anywhere. If a section has no real content,
   leave it out and say so.
3. One primary action per screen. Secondary actions are quiet.
4. Type does the work: hierarchy from size and weight, not from
   colour alone. Check contrast for body text.
5. Prototype in the sandbox: HTML/React artifacts preview live and
   accept tweaks; a prototype that cannot be opened is not done.

## Output

A previewable artifact plus a note on what content is still missing,
if any. Missing content is stated, never padded with filler.
