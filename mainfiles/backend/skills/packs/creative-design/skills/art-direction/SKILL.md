# Art direction

## When to use

The user wants a designed artifact (page, slide, prototype, image
brief) with a point of view, not a generic layout.

## Rules

1. State the direction in one sentence first: audience, feeling,
   and the single thing to notice. If you cannot state it, ask.
2. Reference before generating: name the reference (an existing
   artifact, a brand profile, or a style preset) instead of describing
   a vibe in the abstract.
3. Check visually: open the rendered artifact and look at it. Report
   what you actually saw — spacing, contrast, overflow — not what the
   generator claimed.
4. One critique pass, then stop: list at most three concrete fixes,
   apply them, and re-check. Do not iterate endlessly.
5. Never present a generated image as a photograph of a real thing,
   and never claim a visual check happened when it did not.

## Output

The artifact, the one-sentence direction, and the visual-check notes.
