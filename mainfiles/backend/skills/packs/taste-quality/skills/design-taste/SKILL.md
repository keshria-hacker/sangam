# Design Taste

Sangam-native frontend taste discipline. The rule is simple: remove
ornaments AND add substance. Removing decoration alone leaves a page
thin; adding decoration alone leaves it cluttered.

## Substance first

- Larger, confident type for the thing the page is about; small grey
  text is for metadata, never for the main message.
- Fields of colour: one or two deliberate colour blocks that organise
  the page, not a rainbow of accents.
- Real content over placeholders: real headings, real numbers, real
  pictures. A page full of "Lorem ipsum" cannot be judged and must
  not be shipped as finished.

## Ornament budget

- Every decorative element must earn its place: if removing it changes
  nothing about understanding, remove it.
- No generic gradient blobs, no stock icon soup, no border for the
  sake of a border.

## Before shipping — the rubric

1. What is the page about, in one sentence? If you cannot say it,
   the hierarchy is wrong.
2. What is the first thing the eye lands on? It must be the main
   message, not a decoration.
3. Is there at least one substantive element (real data, real image,
   real comparison) that would be missed if removed?
4. Would this page still read well with all colour removed? If not,
   structure — not colour — is doing the work it should not do.
