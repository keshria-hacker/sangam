# Citation verification checklist (lazy reference)

Read this only when verifying a draft that needs the full procedure.

1. Parse the References section: one entry per line, numbered `[n]` or
   `Author (Year)` style. Record every entry id.
2. Scan the body for in-text citations: `[n]` markers and
   `(Author, Year)` markers. Record every cited id.
3. Report: unresolved citations (cited, no entry), uncited entries
   (entry, never cited), duplicate entries, malformed DOIs.
4. Count `[needs citation]` markers separately — they are gaps, not passes.
5. Never upgrade an unresolved citation to verified by guessing which
   entry it meant; report it and let the author fix the draft.
